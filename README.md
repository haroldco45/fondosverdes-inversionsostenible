# 🌿 FondosVerde — Inversión Sostenible PWA

Aplicación web progresiva educativa sobre fondos de inversión sostenible en Colombia.

## 📱 Características

- **5 secciones**: Fondos, Aprende, Glosario, Quiz, Simulador
- **Instalable** como app nativa (PWA)
- **Funciona offline** via Service Worker
- **Diseño mobile-first** optimizado para celular

## 💼 Fondos incluidos

| Fondo | Rentabilidad | Riesgo |
|-------|-------------|--------|
| Biofertilizantes | 14.2% EA | Bajo |
| Energía Renovable | 11.8% EA | Medio |
| Economía Circular | 9.5% EA | Bajo |
| Agro Sostenible | 16.3% EA | Medio-Alto |

## 🚀 Despliegue

Sube a GitHub Pages o Netlify. Solo HTML/CSS/JS, sin dependencias.
